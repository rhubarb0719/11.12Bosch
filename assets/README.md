# 素材

品牌方素材按型号分文件夹放在这里（仓库为私有，素材随 main 分支入库）：

```
assets/<型号> <颜色>/ID photo/                产品标准照（含斜侧、开门、细节特写）
assets/<型号> <颜色>/home-insetting picture/  家居嵌入实景图
assets/<型号> <颜色>/其他/                    PDP、安装图、海报等参考
```

例：`assets/KCG89AA21C 润玉白/ID photo/KCG89AA21C_右斜侧45度.jpg`

注意：素材含未公开信息，仓库必须保持私有。
