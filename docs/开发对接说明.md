# 开发对接说明

## 出图流程

1. 选型号：从素材库取该型号的**正面产品图**（图1）和一张**家居嵌入实景图**（图2）。
2. 内容 JSON（主标题、副标题、卖点）+ `styles/cover-home/style.json` → `prompt.build_request()` 拼请求体（随机项每类抽一项）。
3. `POST /unified/v1/images/edit-tasks`，`image` 按 [图1, 图2] 顺序传入。
4. 轮询 `GET /unified/v1/tasks/{id}/wait` 至 `completed` / `failed`，立即转存 `data[].url`。

## 请求体固定参数

`model=qwen-image-3.0-pro`，`aspect_ratio=3:4`，`quality=2K`，`provider_options.prompt_extend=false`；seed 每张随机并记录。

## 出图后自动核对（建议）

- **比例**：检测冰箱外框，宽高比应约为 892:1925（≈0.463），偏差超过阈值淘汰。
- **颜色**：在冰箱门板取区域平均色，与图1同区域比较色差，超过阈值淘汰。
- **文字**：人工抽检或 OCR，确认只有指定文字。

## 注意

- 并发 ≤3；`upstream_rate_limited` 时等待后重新提交（`cli.py` 已实现）。
- POST 带 `Idempotency-Key`，网络超时用同一键重试。
- 结果链接会过期，出图后立即转存。
- 素材与规格含未公开信息，仓库必须保持私有；素材放在 `assets/<型号> <颜色>/` 下。
