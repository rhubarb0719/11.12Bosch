## 固定风格

```
小红书冰箱种草笔记封面，竖版3:4。以真实家居摄影为主体：明亮温馨的家庭厨房，冰箱以全嵌入方式装在橱柜里；在照片上叠加简洁的标题和卖点贴纸，整体活泼但有质感，配色柔和，不用荧光色和高饱和撞色；画面中不另加任何品牌标志或 logo 图形；高清，摄影级写实。
```

## 随机项

| 类别 | 选项 |
|---|---|
| 构图 | 1. 冰箱位于画面左侧约三分之一处，右上方是一面干净的浅色墙面，用来放标题<br>2. 冰箱位于画面右侧约三分之一处，左上方是一面干净的浅色墙面，用来放标题<br>3. 冰箱位于画面正中，画面顶部留出一条干净的浅色墙面区域放标题 |
| 产品大小 | 1. 冰箱高度约占画面高度55%<br>2. 冰箱高度约占画面高度65%<br>3. 冰箱高度约占画面高度75% |
| 厨房风格 | 1. 奶油风：奶油白平板柜体、浅木色台面<br>2. 原木风：浅橡木柜体、白色石材台面<br>3. 法式：浅灰绿柜体、细黄铜拉手、白色石材台面<br>4. 极简：浅暖灰柜体、白色台面 |
| 光线 | 1. 上午自然日光从侧窗照入，色温中性<br>2. 午后柔和日光，色温中性略暖<br>3. 室内柔和顶光加少量灯带，色温中性 |
| 摆件 | 1. 台面上一盆小绿植和一碗新鲜水果<br>2. 台面上一只陶瓷花瓶和几枝花<br>3. 台面上一块木砧板和一篮面包 |

冲突：构图 3（居中）不与产品大小 3（75%）同时出现。

## 文字约束

```
画面中新增的文字只允许是：主标题"{主标题}"、副标题"{副标题}"、卖点{卖点}，每段只出现一次，字形清晰、完全准确，数字和单位按原样写出，不要把卖点拆开或重新组合；冰箱门上原有的铭牌保持图1原样。除此之外不要添加任何其他文字、字母、数字、型号、品牌标志、logo 或水印。
```
